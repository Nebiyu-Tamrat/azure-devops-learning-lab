## Working Method

Each meaningful change follows a structured engineering workflow:

1. Create or select a GitHub issue.
2. Create a dedicated local branch.
3. Implement and test the change.
4. Make focused commits with meaningful messages.
5. Push the branch to GitHub.
6. Open and review a pull request.
7. Verify automated checks.
8. Merge the change into `main`.
9. Update the project documentation and learning record.
